# LPF Explorer

**Find your photographs. Not another photo library.**

LPF Explorer is a lightweight, native macOS application for browsing and searching photographs stored in ordinary folders.

It is designed to work with existing photo archives and XMP metadata, without importing photographs into a proprietary library or uploading anything to the cloud.

## Features

- Browse existing folders and subfolders
- Search filenames, titles, descriptions, keywords, and locations
- Filter by star rating, capture date, Finder workflow tags, and file availability
- Work with RAW and JPEG photographs
- Create manual and smart collections
- View photograph metadata
- Open photographs in external editing applications
- Hand selected photographs over to LPF Organizer for metadata editing

## Requirements

- macOS 14 or later
- LPF Organizer V1.0.1 or later for the Organizer handoff feature

LPF Explorer can also be used independently of LPF Organizer.

## Download and installation

1. Open the [latest release](https://github.com/lespetitesfugues/LPF-Explorer/releases/latest).
2. Download `LPFExplorer-1.0.0.zip`.
3. Double-click the ZIP file to extract **LPF Explorer.app**.
4. Move **LPF Explorer.app** to your Applications folder.
5. Launch the application normally.

**LPF Explorer is signed with an Apple Developer ID certificate and notarized by Apple.** No special security settings or Gatekeeper workarounds are required. On first launch, macOS may display its normal confirmation that the application was downloaded from the internet.

## Companion application

**LPF Organizer** handles photograph organization, culling, and XMP metadata editing.

Together, LPF Explorer and LPF Organizer provide a simple, filesystem-based photo workflow.

## Privacy

LPF Explorer works with local files and folders. No cloud account or proprietary photo library is required. The app makes an HTTPS request to `lpf.one` to check for software updates; it does not upload your photographs or their metadata.
